# Scientific figures

All eight figures are provided as PNG, vector PDF and SVG, with file hashes in [index.json](index.json). Figure 1 shows the common interface and fitting-derived routing scale. Figures 2 and 3 retain every seed in the completed matched study. Figures 4–8 describe the separate original readout, sensor-observation, action and timing studies. The camera/radar examples are recorded data with documented selection and dataset attribution.

Regenerate all figures with `python reproduce_results.py --output outputs/check`. Included operands are sufficient for that analysis; no training or dataset download is needed.
